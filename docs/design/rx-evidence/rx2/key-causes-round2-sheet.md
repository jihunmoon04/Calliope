# RX2 핵심 원인 검수 2차 (A2: 인과 사슬, 결정적 원인 1개)

1차 의견을 반영해 다시 쓴 초안이에요. 원인마다 **역할**(결정적/보조)과 **근거 경로**를 붙였어요.
- `digest에 있음`: 에이전트가 `ply`로 받는 정보에 근거가 있어요.
- `요청해야 함`: 에이전트가 `explore` 등으로 직접 확인해야 하는 근거예요. 제가 칼리오페로 그 요청을 실제로 실행했고, 결과를 원인 아래에 붙였어요. 기물은 백 기준 점수이고, 수순을 시작한 국면을 0으로 셉니다.

**검수 방법:** 1차와 같아요. 원인 줄 끝에 `OK` / `수정: …` / `삭제`, 장면 끝에 `추가: …`. 표시가 없으면 승인으로 봐요.
