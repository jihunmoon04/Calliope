동결(freeze_v1, 2026-11-08) 뒤에 연 Test 네 대국의 12장면에 핵심 원인 초안을 썼어요. 규칙은 RX2와 같아요(RX2-D §4.2, A2, A3): 원인은 인과 사슬(둔 수 → 상대의 구체적 응수나 수순 → 물질·메이트·아무것도 못 얻음), 장면마다 **결정적** 1개와 **보조** 최대 2개, 포지션 원인은 쓰지 않아요.
- `digest에 있음`: 에이전트가 `ply`로 받는 정보에 근거가 있어요.
- `요청해야 함`: 에이전트가 `explore`로 직접 확인해야 하는 근거예요. 칼리오페로 그 요청을 실제로 실행했고(`python -m tools.rx requests test`), 결과를 원인 아래에 붙였어요.

- 기물은 백 기준 점수이고, 수순을 시작한 국면을 0으로 셉니다. 평가도 백 기준이에요. 원인 문장의 평가는 참조(digest)의 값이에요.
