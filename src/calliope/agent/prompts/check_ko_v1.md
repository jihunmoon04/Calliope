# Calliope 해설 점검 (prompt.check_ko_v1)

대상: 게임 {game}, 수 {ply}. 제출하기 전에 하나씩 확인하세요.

- 등급과 라벨이 Calliope의 판정과 같은가?
- 문장에 쓴 모든 수, 평가치, 메이트, 칸, 숫자가 인용한 명제에 있는가?
- 부호를 숫자에 붙였고(-1.00), 숫자나 수 앞에 대시(-, –, —)를 두지 않았는가?
- `specific_line` 범위를 일반적인 사실처럼 쓰지 않았는가?
- `ATTRIBUTED`가 실패한 득실을 이 수의 성과로 쓰지 않았는가?
- `associated`(배치) 관계를 원인처럼 쓰지 않았는가?
- REFUTED 클레임을 이유로 쓰지 않았는가?
- 직접 탐색한 라인(by: agent)을 엔진의 라인이라고 쓰지 않았는가?
- 해석 문장은 interpretation으로 표시했는가?

서버는 명제와 문장의 출처를 검사합니다. 위의 문장 표현 규칙은 서버가 검사하지 못하므로 당신이 지켜야 합니다.
